v. 1.0.1 - 2026-11-09
- **Native Core Search**: one concurrent pass across all sources with a global time budget and automatic retries.
- **Smarter & Cleaner Results**: JSON site APIs, WordPress and RSS feeds, POST search forms, per-site sessions and relocated domains understood; ads, redirect links, category, tag and listing pages filtered out.
- **Streamlined Network Layer**: lean, direct requests make Core search more than twice as fast.
- **Fresh Core for All Platforms**: newly built for Windows, macOS (Apple Silicon & Intel), Android (64-bit & 32-bit) and Linux (x86_64 & aarch64).

v. 1.0.0 - 2026-11-03
- On-demand platform architecture detection and binary delivery (`windows-x86_64`, `android-arm64-v8a`, `android-armeabi-v7a`, `darwin-arm64`, `darwin-x86_64`, `linux-x86_64`, `linux-aarch64`).
- Interactive installation notice and progress dialog when the platform Core binary is missing, with live background activation without restarting Kodi.
- High-performance native Rust Core engine (`127.0.0.1:8191`) for concurrent search, dynamic player evaluation, session pooling, and local stream/artwork relaying.
