v. 1.0.4 - 2026-11-25
- **Android / Google TV Loader**: Copy the shared library with raw byte copy (`copyfile`), apply read-only `0555` permissions, fall back across all internal app directories before skipping external `/storage/` paths, and handle existing read-only files cleanly.
- **Retry Cap**: Stop automatic Core startup retries after 5 consecutive failures so Kodi logs stay clean when an OS/device policy blocks execution.

v. 1.0.3 - 2026-11-18
- **Site Profiles**: the Core runs AdultHideout's own search patterns for 57 more websites, so 281 sources now search directly in the Core.
- **Failure Reasons**: the Core reports why a website failed (offline, not found, rate limited, Cloudflare) and does not retry after a timeout, so Global Search skips pointless retries.
- **Honest Challenge Status**: an unsolved Cloudflare challenge is reported as an error instead of a success.
- **Diagnostics Support**: the Core reports the final address and page language of every website.
- **Fresh Core for All Platforms**: newly built for Windows, macOS (Apple Silicon & Intel), Android (64-bit & 32-bit) and Linux (x86_64, aarch64 & armv7).

v. 1.0.2 - 2026-11-11
- **Core for 32-bit ARM Linux**: CoreELEC, LibreELEC and Raspberry Pi systems running a 32-bit Kodi now get the native Core engine (`linux-armv7`), with full Core search.
- **Precise Platform Detection**: Kodi's own architecture decides which Core is installed.
- **Calm Engine Start**: smarter retry pacing keeps the system responsive.

v. 1.0.1 - 2026-11-09
- **Native Core Search**: one concurrent pass across all sources with a global time budget and automatic retries.
- **Smarter & Cleaner Results**: JSON site APIs, WordPress and RSS feeds, POST search forms, per-site sessions and relocated domains understood; ads, redirect links, category, tag and listing pages filtered out.
- **Streamlined Network Layer**: lean, direct requests make Core search more than twice as fast.
- **Fresh Core for All Platforms**: newly built for Windows, macOS (Apple Silicon & Intel), Android (64-bit & 32-bit) and Linux (x86_64 & aarch64).

v. 1.0.0 - 2026-11-03
- On-demand platform architecture detection and binary delivery (`windows-x86_64`, `android-arm64-v8a`, `android-armeabi-v7a`, `darwin-arm64`, `darwin-x86_64`, `linux-x86_64`, `linux-aarch64`).
- Interactive installation notice and progress dialog when the platform Core binary is missing, with live background activation without restarting Kodi.
- High-performance native Rust Core engine (`127.0.0.1:8191`) for concurrent search, dynamic player evaluation, session pooling, and local stream/artwork relaying.
