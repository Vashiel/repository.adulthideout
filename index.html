Install In Kodi

  1. Open Kodi and go to Settings, then File manager.
  2. Select Add source and enter https://vashiel.github.io/repository.adulthideout/.
  3. Name the source AdultHideout.
  4. Open Add-ons, choose Install from zip file, then select repository.adulthideout-1.0.5.zip.
  5. Use Install from repository to install or update AdultHideout from Video add-ons. Optional AdultHideout Diagnostics is available separately under Program add-ons.

About This Repository

AdultHideout is an adult-oriented Kodi addon project built around Global Search, Vault and a managed Download Center. Beacon makes that foundation personal through optional website collections and direct skin search, adds platform-native Diagnostics, expands the source catalog and repairs difficult playback routes. The new Wiki serves as the user handbook. AdultHideout 1.0.20.1 "Beacon Hotfix" additionally repairs Diagnostics installation and startup.

This page is the canonical public homepage for the repository source. It is intended for adults only and does not replace the Kodi installation workflow.
