# The AdultHideout Wiki is now live

AdultHideout has grown far beyond the small addon it started as, and the README was no longer the right place to explain every useful feature. The new official Wiki gives each part of AdultHideout room to breathe while keeping the repository front page focused.

The Wiki includes illustrated English guides for installation, website discovery and filters, Global Search, Vault, Download Center, Diagnostics and optional skin integration. The screenshots use Kodi's standard Estuary skin and a clean default AdultHideout setup.

It also includes a dedicated guide for reporting problems. Before opening an issue, please search for an existing report and collect the essentials:

- your operating system and Kodi version;
- your AdultHideout version;
- the affected website or feature;
- clear steps to reproduce the problem;
- what you expected and what actually happened;
- an AdultHideout Diagnostics report when available;
- a Kodi debug log for playback, network or platform-specific failures.

The guide explains how to use Kodi Logfile Uploader, where Diagnostics reports are saved and how to check files for private information before sharing them.

Some of the skin-integration guidance grew directly from community feedback, including the Arctic Fuse setup shared in issue #67. That setup showed a use of AdultHideout I had not considered before and helped shape the optional website collections and direct skin-search support in 1.0.20 "Beacon."
