# AdultHideout 1.0.20.1 "Beacon Hotfix"

This focused update repairs the optional AdultHideout Diagnostics integration introduced with Beacon.

- Kodi now presents one native confirmation when Diagnostics is not installed.
- AdultHideout waits for Kodi's local add-on registry before launching a newly installed companion.
- Diagnostics and its background worker now load through isolated module names, preventing conflicts with Python packages exposed by other Kodi add-ons.
- AdultHideout Diagnostics is updated to version 0.2.1.

All other Beacon features remain unchanged.
