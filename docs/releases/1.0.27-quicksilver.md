# AdultHideout 1.0.27 "Quicksilver"

**Released November 9, 2026**

AdultHideout 1.0.27 unlocks the full potential of **AdultHideout Core**, the native Rust engine introduced with Core Horizon. Global Search and Mega Shuffle now run natively from the first request to the last result: every source is queried by the Core in a single pass, with AdultHideout's website modules seamlessly covering the rest. The result is our fastest, most complete and cleanest search ever, backed by more than two dozen refreshed websites.

### Native Core Search

Core Horizon laid the foundation. Quicksilver hands the entire Global Search to it:

- **One Pass, Every Source:** All 300+ websites are queried by AdultHideout Core in a single concurrent request with a global time budget and automatic retries. AdultHideout's website modules take over wherever a site needs its dedicated logic, so every source stays part of the search.
- **Smarter Result Recognition:** The Core now understands JSON site APIs, WordPress and RSS feeds, POST search forms, per-site sessions, regional and relocated domains, and Cyrillic titles, so far more sources deliver matches.
- **Cleaner Results:** Ads, redirect links, category, tag and listing pages are filtered out automatically, leaving only real videos.
- **Streamlined Network Layer:** Lean, direct requests make the Core search more than twice as fast as before.

### Key Technical Subsystems in AdultHideout Core

- **Concurrent Multi-Site Search Engine:** Queries every source in one pass with parallel workers, a global time budget, automatic retries and intelligent result filtering.
- **Local HLS & MP4 Stream Relay (`127.0.0.1:8191`):** Rewrites adaptive HLS (`.m3u8`) playlists to auto-select 1080p Full HD variants and handles HTTP 206 byte-range seeking for smooth MP4 playback.
- **Embedded QuickJS Runtime:** Evaluates packed player scripts and signed stream ticket APIs in milliseconds.
- **On-Demand Platform Binary Delivery (~3 MB):** Detects the device and downloads only the matching binary, starting it instantly with no Kodi restart. Quicksilver ships a freshly built Core for all seven platforms: Windows, macOS (Apple Silicon & Intel), Android (64-bit & 32-bit) and Linux (`x86_64` & `aarch64`).
