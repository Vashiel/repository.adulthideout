# AdultHideout 1.0.27 "Quicksilver"

**Released November 9, 2026**

AdultHideout 1.0.27 puts AdultHideout Core in charge of Global Search. In 1.0.26 the Core was mainly a helper for the Python modules; now all sources are searched through the Core in one request, and the Python modules only take over where the Core cannot. The release also repairs search or playback on 27 websites and keeps installed Core binaries up to date.

---

### Core-First Global Search

Global Search and Mega Shuffle send all sources to the Core at once. Sources the Core cannot handle, and sources whose request fails in the Core, are searched by their Python module afterwards, so no source is left out because of the Core.

Measured with Mega Shuffle (302 sources) on Windows: about **18 seconds**, with more results than the Python search alone. Twelve sources stay on their Python module by design (see below).

The Core search now:
- reads JSON site APIs (for example the txxx network), WordPress and RSS feeds, and search forms sent by POST,
- sends per-site cookies, follows sites that moved to another domain and keeps exact page URLs,
- matches Cyrillic titles against Latin search terms,
- rejects ads and redirect links (for example "Live Sex Cams"), category and tag pages, and listing pages that only repeat the search term,
- stops after an overall time limit, so one slow website cannot hold back the whole search.

### Content Filters Preserved

Some website modules filter their results: blocked terms, ratings or orientation settings. The Core cannot apply those rules, so these sources (among them Iwara, HentaiMama, Hentaisea and XVideos) keep searching through their own module. In addition, every Core result is checked against the same blocked terms before it is shown.

### Automatic Core Updates

Until now the Core service only checked whether its binaries existed, so an installed Core was never replaced. Core Service 1.0.1 compares the installed version with the current one and downloads newer binaries on the next start, before the engine is loaded. If the download fails, the installed Core keeps running and the next start tries again. Core 1.0.1 is available for all seven platforms (Windows, Android 64/32-bit, macOS Apple Silicon and Intel, Linux x86_64 and aarch64).

### Known Limits

- On phones the Core is fast on its own, but when many sources fall back to Python the search can take noticeably longer than on desktop.
- A few websites block automated access or protect their players; they may still return no results or no playable stream.
