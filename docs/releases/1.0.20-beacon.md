# AdultHideout 1.0.20 "Beacon"

Beacon makes a much larger AdultHideout feel personal again.

- Create optional website collections and use them as Kodi folders or compatible skin widgets.
- Send skin searches directly to AdultHideout without opening Kodi's keyboard.
- Install and launch the new optional AdultHideout Diagnostics 0.2.0 companion from **AdultHideout Settings → General**.
- Use the new official Wiki as the illustrated AdultHideout handbook.
- Configure writable storage through a guided fallback, then use a serial built-in queue with fresh links on retry.
- Explore 15 newly integrated websites.
- Benefit from broad repairs to protected artwork, Cloudflare routes, APIs, HLS extraction, resolvers and seeking.

The Stronghold foundation remains intact: Global Search, Vault, Download Center, SMB/NFS destinations and Offline videos continue to work as before.

Beacon also ships **AdultHideout Repository 1.0.5**, the first repository-package update since Jubilee. It adds AdultHideout Diagnostics as a separately installable Program add-on.

Full details are available in the [changelog](https://github.com/Vashiel/repository.adulthideout/blob/master/plugin.video.adulthideout/changelog.txt) and [AdultHideout Wiki](https://github.com/Vashiel/repository.adulthideout/wiki).
