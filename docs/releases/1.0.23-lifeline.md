# AdultHideout 1.0.23 "Lifeline"

**Released September 14, 2026**

Lifeline is a focused maintenance release for AdultHideout's growing website catalog. It reconnects sources that are working again, repairs broken listing and playback paths, and removes dead ends that no longer belong in the main addon.

That is why this release is called **Lifeline**.

## Six Websites Return

**HentaiMama, HQPorner, OGPorn, SaintPorn, SwingerPornFun and VintagePornFun** return after renewed listing, artwork, playback and seek checks. Their old Diagnostics exemptions have been removed, so future tests evaluate them normally instead of silently ignoring them.

HentaiMama now uses its current player API and filters unavailable placeholders. OGPorn can use targeted range emulation for its non-compliant CDN, while SwingerPornFun keeps only entries backed by working resolver mirrors.

## Two New Websites

Lifeline adds **HomeMoviesTube** and **Porno24**. HomeMoviesTube artwork is delivered through AdultHideout's existing memory-only thumbnail proxy when Kodi cannot load it directly. Porno24 uses a direct detail transport that substantially reduces its previous playback startup delay.

## Repairs And Cleanup

Porn7 supports the site's current data-attribute listings, and BDSM Villa uses the stable requests-backed range transport for playback. Stripchat exposes its available language filters and can also show country or region filters when its public metadata supplies them.

**CzechVideo** was removed after remaining inaccessible behind an HTTP 403 challenge. **XoxPorn** was removed after its domain stopped publishing DNS records.
