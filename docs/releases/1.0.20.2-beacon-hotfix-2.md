# AdultHideout 1.0.20.2 "Beacon Hotfix 2"

Released August 9, 2026.

This hotfix repairs Android downloads that completed successfully in AdultHideout's private staging storage but could not be transferred into a public Download or Video folder because Android exposed the locations through different filesystems.

Direct-file resume handling also recovers when a host returns HTTP 416: an already complete staging file is finalized, while an invalid partial file is restarted cleanly without a permanent queue failure.

The Diagnostics installation and startup fixes from AdultHideout 1.0.20.1 remain included.
