AdultHideout began in **January 2016** as a small personal Kodi addon for one website. Ten years later, it connects hundreds of sources, searches across them, preserves discoveries in Vault and manages downloads across local and network storage.

**Beacon brings that larger AdultHideout back into focus.** Personal website collections, direct skin integration and platform-native diagnostics make its depth easier to reach without making the default experience heavier.

## Beacon: AdultHideout, Made Yours

### Your Websites. Your Home Screen.

Optional **Website Collections** let you group the sources that matter to you. Create Favorites, My Top Sites or completely custom collections, then use them as normal Kodi folders or home-screen widgets in compatible skins.

Beacon also introduces a direct, non-interactive search endpoint. Compatible skins can pass their own search term to AdultHideout and display clean video results without opening another keyboard or launching a complete Global Search on every keystroke.

This began with an AdultHideout user who shared his carefully customized Kodi setup. Beacon brings that idea directly into AdultHideout, allowing the same kind of personal home screen without rebuilding the addon around it.

## The Stronghold Foundation

**Stronghold and Rampart** transformed AdultHideout from a website browser into a complete discovery and collection system. Beacon keeps that combined foundation at its center:

- **Global Search** searches selected sources, removes duplicate clutter and preserves its results.
- **Vault** turns discoveries into Watch Later and personal collections with multi-select, search, cleanup, backup and restore.
- **Download Center** manages background downloads, progress, queues and history.
- **Offline videos** returns completed downloads to Kodi from local, SMB or NFS storage.
- **Website discovery** sorts, filters and organizes an increasingly large catalog.
- **Playback intelligence** evaluates qualities, mirrors and difficult stream routes before playback begins.

Beacon does not replace that foundation. It makes more of it accessible.

## Built To Find Problems Earlier

Maintaining hundreds of websites by hand is no longer realistic. Waiting for every problem to appear as a GitHub issue is not enough either.

Beacon gives AdultHideout something unusual: its own optional diagnostics companion running directly inside Kodi.

A single website, a selected group or the complete catalog can be tested on the device where AdultHideout is actually installed, whether that is Windows, Android, Linux or macOS.

The privacy-safe report helps identify empty listings, broken artwork, timeouts and platform-specific failures earlier, without asking users to discover every problem first.

Open **AdultHideout Settings → General → AdultHideout Diagnostics → Open diagnostics**. The launcher is always available; if Diagnostics is missing, AdultHideout offers to install it automatically from the AdultHideout Repository.

## Installation

Beacon also updates the **AdultHideout Repository to version 1.0.5**, its first repository-package update since the Jubilee release. This makes AdultHideout Diagnostics available as a separate optional Program add-on alongside AdultHideout itself.

1. In Kodi, open **Settings → File manager → Add source**.
2. Enter `https://vashiel.github.io/repository.adulthideout/` and name it `AdultHideout`.
3. Open **Add-ons → Install from zip file** and install `repository.adulthideout-1.0.5.zip`.
4. Select **Install from repository → AdultHideout Repository**.
5. Install **AdultHideout** from Video add-ons.
6. Optional: install **AdultHideout Diagnostics** from Program add-ons.

Direct download: [repository.adulthideout-1.0.5.zip](https://github.com/Vashiel/repository.adulthideout/raw/master/repository.adulthideout-1.0.5.zip)
