<h1 align="center">AdultHideout</h1>
<p align="center">

  Adult-oriented video discovery, playback, search, collections and downloads for Kodi.
</p>

AdultHideout began in **January 2016** as a small personal Kodi addon for one website. It has grown into a cross-platform media browser that brings hundreds of third-party sources into one consistent Kodi interface.

AdultHideout does not host videos. It organizes publicly available listings and hands playback to Kodi while adding the tools a large source catalog needs: Global Search, Vault, downloads, website filters, resolver preferences, diagnostics and optional skin integration.

## Current Release

**AdultHideout 1.0.22 "Atlas"** was released on **August 30, 2026**.

Atlas adds **Complete Backup & Restore**, optional **Continue Watching**, account-free **Cam Favorites**, public **PornHub Playlists**, Mega Shuffle, richer website views and eleven new sources. It also strengthens Smart Streams, exact-uploader navigation, persistent Kodi views and catalog-wide diagnostics.

The name **Atlas** reflects what this release does: AdultHideout has grown into a world of hundreds of sources and personal paths through them. Atlas makes that world easier to navigate, preserve and revisit.

## What AdultHideout Can Do

- Browse hundreds of supported websites through one Kodi interface.
- Search selected sources together with **Global Search** and keep reusable search history.
- Save videos to **Vault**, organize collections, rate entries and build a personal Vault TV channel.
- Download supported streams through the managed **Download Center** to local, SMB or NFS storage.
- Play completed downloads through **Offline videos**.
- Sort and filter the website catalog by name, age and content category.
- Choose preferred resolvers and skip mirrors that do not work well on a device.
- Create optional website collections for custom Kodi home screens and compatible skins.
- Run privacy-safe tests with the optional **AdultHideout Diagnostics** companion.
- Explore performers and known full-length titles through **Star Finder (Beta)**.
- Build continuously refilled personal channels with **Smart Streams (Beta)**.

## Supported Platforms

AdultHideout targets **Kodi 19 or newer** and uses Kodi's Python 3 runtime. It is designed for:

- Windows
- Android and Google TV / Fire TV
- Linux, LibreELEC and CoreELEC
- macOS

Individual websites can behave differently across platforms because their servers, CDNs and protection systems change independently of AdultHideout. Diagnostics can test the addon directly on the affected device.

## Installation

1. In Kodi, open **Settings → File manager → Add source**.
2. Enter `https://vashiel.github.io/repository.adulthideout/` and name it `AdultHideout`.
3. Open **Add-ons → Install from zip file** and install `repository.adulthideout-1.0.5.zip`.
4. Select **Install from repository → AdultHideout Repository**.
5. Install **AdultHideout** from **Video add-ons**.
6. Optional: install **AdultHideout Diagnostics** from **Program add-ons**.

Direct repository download: [repository.adulthideout-1.0.5.zip](https://github.com/Vashiel/repository.adulthideout/raw/master/repository.adulthideout-1.0.5.zip)
