v. 1.0.1 - 2026-11-09
- New Core engine (all seven platforms): one request searches all sources with an overall time limit, reads JSON site APIs, feeds and POST search forms, follows moved domains and rejects ads, category and tag pages.
- Automatic updates: the service compares `version.txt` with the current Core version and downloads newer binaries before the engine is loaded. If that fails, the installed binaries keep running.

v. 1.0.0 - 2026-11-03
- On-demand platform architecture detection and binary delivery (`windows-x86_64`, `android-arm64-v8a`, `android-armeabi-v7a`, `darwin-arm64`, `darwin-x86_64`, `linux-x86_64`, `linux-aarch64`).
- Interactive installation notice and progress dialog when the platform Core binary is missing, with live background activation without restarting Kodi.
- High-performance native Rust Core engine (`127.0.0.1:8191`) for concurrent search, dynamic player evaluation, session pooling, and local stream/artwork relaying.
